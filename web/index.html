Camera

body · lens · aperture

Focal length is ours, not 4.0's. It was one of the three original 1.0 controls and is still named in the 2.0/3.5 material, but it is absent from the 4.0 settings reference, the help-centre walkthrough, and the API schema — 4.0 ships four bodies and five lenses with no focal control. This engine keeps it first-class, so it appears here in its own engine extension block and never in the parameter block.

Camera movement

stackable — they run in order

    Each move is carried in the prompt as a # tag. Stack several and they run in the order shown — that ordering is the whole point of the panel.

    Lighting & colour

    named looks, not prompt words

    Emotion wheel

    per character

      Nine emotion names — the union of the on-screen wheel (which showed eight) and the settings reference (which enumerates eight, differing by Hope vs Interest). The wheel is visibly larger than its visible arc, so this is a floor. One tutorial claims 80 emotions across three strength levels; that is unverified and we do not implement it.

      Intensity is continuous 0–1, and the three words are descriptors, not enum members. The evidence claims three strength levels but no strength control was legible in any frame, so the cut points are unknown — inventing three would be padding. The published API has no emotion field at all, so this group is shown in the plan but never sent.

      Why this pairing is the entry
      
        
      
        
      
          Re-shooting a subject from a chosen angle is not new — other entries in
          this competition already do it in image space, and one ships a Cinema Studio tab of its
          own. What none of them does is measure the result. This tab sets
          the parameters; the Judge tab measures the frame that comes back against
          nine cinematography rules and hands you a correction in metres. Setting is commodity.
          Verifying is the entry.
